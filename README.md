# Eye of the Storm Plus

Deep Aether 的风暴之眼 Boss 强化附属模组。加入三阶段战斗、10 个战斗技能、转阶段怒吼及额外风暴特效。

## 版本

- `1201forge`：Minecraft 1.20.1，Forge，Java 17。
- `1211neoforge`：Minecraft 1.21.1，NeoForge，Java 21，已完成迁移与服务端/渲染验证，见 [迁移文档](https://github.com/hp3081925122/EotsPlus/blob/1211neoforge/MIGRATION_1211_NEOFORGE.md)。

## 功能

破空俯冲、风晶裂弹、缠风绞环、回旋风刃、蛇行雷痕、逆鳞风雨、风眼连珠、裂空风矛、风棱阵、蜕鳞旋风、风暴坍缩，以及阶段切换怒吼。待机悬浮高度默认降为控制器上方 8 格（可配置）。默认阶段阈值为 60% 和 25% 生命值；属性、阶段和技能参数支持配置。

需要 Deep Aether 与 The Aether，以及其对应版本的前置依赖。

## 构建

使用对应版本的 JDK 执行 `./gradlew build`。构建成功不代表所有技能或客户端渲染均已实测。
